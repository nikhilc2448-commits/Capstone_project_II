# Capstone Project II – Full Analytics & Insights System

## Overview

End-to-end analytics project using Customer and Order datasets. The project covers data cleaning, analysis, statistics, visualization, SQL, Excel, Power BI, customer segmentation, KPIs, and business insights.

## Tools

- Python
- NumPy
- Pandas
- Matplotlib
- SciPy
- Scikit-learn
- SQL
- Excel
- Power BI
- Git & GitHub

## Modules

### Module 1 – Data Audit & Cleaning
Initial/final audit, missing values, duplicates, text standardization, data types, referential integrity, orphan CustomerID handling, and cleaning log.

### Module 2 – Python & NumPy
Modular Python functions, exception handling, NumPy calculations, normalization, and `np.where()`.

### Module 3 – Pandas & EDA
Data merging, GroupBy, pivot analysis, derived metrics, IQR outliers, correlation analysis, and interpretations.

### Module 4 – Statistics
Descriptive statistics, mean vs median, two samples of 50, sample comparison, t-test, p-value, and statistical interpretation.

### Module 5 – Visualization
Sales by region, monthly sales trend, sales distribution, sales vs profit, outliers, correlation heatmap, and Elbow Method.

### Module 6 – Excel
Cleaned data, cleaning log, pivot summaries, analysis results, and formula-based KPI report.

### Module 7 – SQL
JOIN, GROUP BY, HAVING, CASE, subquery, CTE, window function, and orphan CustomerID query.

### Module 8 – Power BI
Data model, KPI cards, business visuals, slicers, DAX measures, and Python-to-Power BI cross-check.

### Module 9 – Customer Segmentation
Customer features, StandardScaler, Elbow Method, K-Means clustering, four behavioral segments, and recommendations.

### Module 10 – KPI Reporting
Six business KPIs with users, decisions, and best/worst KPI assessment.

### Module 11 – Business Report
Manager-focused report with numerical insights and business recommendations.
